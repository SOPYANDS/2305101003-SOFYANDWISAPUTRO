**INSTRUKSI PENGUMPULAN HASIL UJIAN TENGAH SEMESTER (UTS)
PEMROGRAMAN MOBILE MELALUI GITHUB**
Setiap mahasiswa diwajibkan mengumpulkan hasil Ujian Tengah Semester (UTS) mata kuliah Pemrograman Mobile melalui GitHub. Repository GitHub digunakan untuk menyimpan source code, dokumentasi, dan bukti hasil implementasi aplikasi mobile sesuai dengan soal serta ketentuan UTS yang diberikan oleh dosen.

A. Ketentuan Umum
Setiap mahasiswa wajib memiliki akun GitHub yang aktif.

Setiap mahasiswa wajib membuat satu repository GitHub untuk mengumpulkan hasil UTS.

Gunakan nama repository dengan format NIM-KELAS-PROJECT, misalnya 2405101043-5E-PROJECT.

Atur visibility repository menjadi Public agar dapat diakses dan diperiksa.

Source code yang dikumpulkan harus merupakan hasil pengerjaan mahasiswa sendiri.

Setiap mahasiswa wajib memperbarui repository dan memastikan seluruh file berhasil diunggah ke GitHub sebelum batas waktu pengumpulan.

Setiap repository wajib memiliki file README.md yang berisi identitas mahasiswa, informasi mata kuliah, deskripsi pengerjaan UTS, teknologi yang digunakan, petunjuk menjalankan aplikasi, dan informasi pendukung lainnya.

Kumpulkan tautan repository melalui media pembelajaran yang telah ditentukan oleh dosen.

B. Struktur Repository
Gunakan struktur folder berikut sebagai acuan.

NIM-KELAS-PROJECT/
├── uts/
│   ├── [source-code-project-mobile]/
│   ├── assets/
│   │   ├── images/
│   │   └── icons/
│   └── screenshots/
│       ├── halaman-utama.png
│       ├── halaman-kedua.png
│       └── hasil-implementasi.png
│
├── README.md
└── [file-pendukung-lainnya]
Catatan:

Struktur folder di atas merupakan contoh dan dapat disesuaikan dengan teknologi serta framework yang dipersyaratkan dalam soal UTS.

Folder uts digunakan untuk menyimpan source code dan seluruh file pendukung pengerjaan UTS.

Folder screenshots digunakan untuk menyimpan bukti visual hasil implementasi aplikasi mobile.

Source code dapat menggunakan struktur bawaan framework atau teknologi yang digunakan, seperti Flutter, React Native, Kotlin, Java, atau teknologi lain sesuai ketentuan soal UTS.

File dan folder bawaan proyek yang diperlukan untuk menjalankan aplikasi tetap harus disertakan.
C. Ketentuan Source Code dan File Pendukung
Seluruh source code yang diperlukan untuk menjalankan aplikasi mobile wajib disertakan.

Susun source code dengan struktur folder yang rapi dan mudah dipahami.

Gunakan nama file, folder, class, dan komponen yang jelas serta sesuai dengan fungsinya.

Implementasi aplikasi wajib mengikuti soal UTS yang diberikan oleh dosen.

Gunakan bahasa pemrograman, framework, dan teknologi yang dipersyaratkan dalam soal UTS.

Pastikan aplikasi dapat dijalankan dan fitur yang diminta berfungsi sesuai ketentuan.

Sertakan seluruh file konfigurasi dan dependensi yang diperlukan untuk menjalankan proyek.

Jangan mengunggah file sementara, cache, folder hasil build, atau folder instalasi dependensi yang tidak diperlukan.

Jangan mengunggah password, token, API Key, atau kredensial rahasia ke repository Public.

Pastikan source code yang dikumpulkan merupakan versi final hasil pengerjaan UTS.

Jika soal UTS mensyaratkan penggunaan database lokal, API, atau penyimpanan data, sertakan konfigurasi dan dokumentasi yang diperlukan agar implementasi dapat diperiksa.

Sertakan file APK apabila diminta secara khusus dalam soal UTS atau instruksi dosen. Jika ukuran file terlalu besar, gunakan media penyimpanan lain dan cantumkan tautannya pada README.md.

D. Ketentuan README.md
File README.md wajib tersedia di direktori utama repository dan memuat informasi berikut:

Judul repository.

Identitas mahasiswa, meliputi nama lengkap, NIM, kelas, dan program studi.

Informasi mata kuliah dan tahun akademik.

Deskripsi pengerjaan UTS.

Teknologi dan framework yang digunakan.

Ringkasan fitur aplikasi yang diimplementasikan.

Struktur folder hasil UTS.

Persyaratan dan petunjuk menjalankan aplikasi.

Informasi lokasi screenshot hasil implementasi.

Informasi file APK apabila tersedia.

Referensi yang digunakan, jika ada.

Gunakan template berikut.

E. Ketentuan Dokumentasi Hasil Implementasi
Setiap mahasiswa wajib menyertakan screenshot hasil implementasi aplikasi mobile.

Screenshot harus memperlihatkan tampilan aplikasi yang benar-benar dijalankan pada emulator atau perangkat mobile.

Screenshot harus sesuai dengan fitur dan halaman yang diminta dalam soal UTS.

Pastikan gambar dapat dibaca dengan jelas dan tidak terpotong.

Simpan seluruh screenshot pada folder uts/screenshots/.

Gunakan nama file yang jelas sesuai dengan halaman atau fitur aplikasi.

Apabila aplikasi memiliki beberapa halaman, sertakan screenshot untuk setiap halaman utama yang relevan.

F. Format Pengumpulan
Pengumpulan dilakukan dengan mengirimkan tautan repository GitHub melalui media pembelajaran yang telah ditentukan oleh dosen.

Pastikan repository dapat diakses tanpa memerlukan permintaan akses tambahan.

Pastikan folder uts, source code, folder screenshots, dan file README.md telah tersedia.

Pastikan seluruh perubahan terbaru telah diunggah ke GitHub.

Pastikan aplikasi dapat dijalankan sesuai petunjuk pada README.md.

Pastikan screenshot hasil implementasi telah tersedia dan dapat diperiksa.

Pengumpulan wajib dilakukan sebelum batas waktu yang ditentukan oleh dosen.

Mahasiswa bertanggung jawab memastikan tautan repository yang dikumpulkan benar dan dapat diakses.

Format pengumpulan:

Nama: [Nama Lengkap]

NIM: [NIM]

Kelas: [Kelas]

Link Repository GitHub: [Tautan Repository]

PERHATIAN:

Setiap mahasiswa bertanggung jawab atas kelengkapan source code, dokumentasi, dan bukti hasil implementasi aplikasi mobile yang dikumpulkan. Repository yang tidak dapat diakses, source code yang tidak lengkap, atau hasil implementasi yang tidak sesuai dengan ketentuan soal UTS dapat memengaruhi penilaian.
